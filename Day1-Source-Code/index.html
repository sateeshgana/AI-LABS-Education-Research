01 What is a hex colour?

A hex colour is a # followed by red, green and blue written in base 16: #RRGGBB. When both digits of a pair match you may write it short — #000000 becomes #000.

#000 = #000000 · pure black · rgb(0, 0, 0)
#111 = #111111 · near black · rgb(17, 17, 17)

Barely a difference, right? Line up all sixteen hex digits and the eye finally catches on. JavaScript builds this strip in a loop — see script.js.
